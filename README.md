# clonekeuanganAsia

Sistem Finansial & Akuntansi Terintegrasi **Asia Plastik**.

## Fitur Utama
- **Dashboard Finansial Real-Time**: Ringkasan saldo kas & bank, piutang (AR), utang (AP), dan arus kas bersih.
- **Autentikasi Firebase**: Terintegrasi dengan Google Auth (`prompt: select_account`) dan Email Login dengan kontrol akses berbasis peran (RBAC: Owner, Finance Manager, dll).
- **Modul Keuangan Lengkap**: Kas & Bank, Rekonsiliasi, Penjualan, Pembelian, Inventori, Perpajakan, dan Akuntansi (COA & Jurnal).

## Menjalankan Proyek
```bash
npm install
npm run dev
```
Buka [http://localhost:3000](http://localhost:3000) di browser Anda.
